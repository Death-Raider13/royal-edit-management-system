# Royal Edit Media House Brand Implementation Notes

The application is a premium internal operations platform for a modern African, technology-focused creative agency. The visual treatment should communicate authority, creativity, strategic intelligence, and polished restraint through a cinematic, editorial interface.

| Brand element | Approved direction | Application use |
|---|---|---|
| Deep Black | `#080808` | Primary shell, sidebar, dark surfaces, and high-contrast panels |
| Primary Gold | `#C9A84C` | Headings, active states, premium highlights, key metrics, and focus accents |
| Warm White | `#E8E0D0` | Primary light text and light surfaces |
| Gold Dim | `#8B6F2E` | Secondary accents, borders, quiet labels, and muted states |
| Burnt Orange | `#FF4D1C` | Urgent calls to action, overdue indicators, and critical status cues |
| Cormorant Garamond | Luxury display typeface | Page titles, large metric values, major report headings |
| DM Sans | Modern body/UI typeface | Navigation, interface copy, forms, tables, and descriptions |
| Bebas Neue | Uppercase display label | Section labels, compact badges, and metadata markers |

The interface will use a black-dominant layout with restrained gold accents, ample negative space, strong typographic hierarchy, lightly textured or cinematic surface treatments, and concise motion. The supplied kit describes the desired tone as confident, intelligent, cinematic, elegant, and business-focused.
